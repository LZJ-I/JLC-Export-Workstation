## KiCad 官方读取

使用官方 Ubuntu 包中的 **KiCad 9.0.9 kicad-cli**，实际对 GUI 同步后的文件执行：

```text
kicad-cli sym export svg --include-hidden-fields UIParts.kicad_sym
kicad-cli fp export svg UIParts.pretty
```

两项退出码均为 0，实际生成 C2040、C25804 和 UserOriginal 的符号、封装 SVG。原有用户符号、封装及无关模型目录文件保留。绑定模型引用指向同名 `.3dshapes` 下的绝对路径。

## 使用范围

KiCad 绑定生成 KiCad 9 格式，较旧符号库同步后升级版本。符号库和封装库需要在 KiCad 中各添加一次，昵称使用文件名，不含扩展名；AD 也需安装文件库一次。后续同步更新原路径，EDA 软件可能需要刷新或重新打开库。

原理图预览读取实际导出记录，由本程序渲染。尚未在交互式 Altium / KiCad 编辑器里执行装库、工程放置、设计规则检查和 3D 视觉验收；不将文件解析及写入测试表述为这些操作已经通过。当前在线搜索源仍是立创。
