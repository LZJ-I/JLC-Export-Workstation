# PADS 原理图连接栅格

入口：**设置 → 导出设置 → 格式 → PADS 原理图 → 连接栅格**。

- 10 mil 为默认值，沿用此前已验证的排版；也可选 50、100 mil，或自定义 1–1000 mil 整数（包含 25 mil）。
- 设置自动保存，单个和批量导出共用；命令行 `get` / `batch` 可用 `--pads-grid 100` 覆盖本次值，省略时读取保存值。
- 改设置后需要重新导出、导入原理图库。在 PADS 中选择相同连接栅格，并在栅格点放置器件。本软件不会修改 PADS 的显示栅格、移动栅格或现有原理图。

## 排版规则

连接点和插入原点具有相同栅格相位，引脚长度及相邻行、列的间距为目标栅格的整数倍。保留引脚编号、方向、顺序、显示开关和原有堆叠关系。对密集引脚预留文字高度所需的空间；例如 100 mil 栅格可以采用 200 mil 行距，不强求相邻引脚只差一个格。

普通独立引脚不会通过四舍五入合并成堆叠引脚。文字保持原有 7 号设置，外框与源图注释跟随引脚调整；斜线在变换分界处细分，带引脚的圆形轮廓以包含连接点的折线表达，防止图形与引脚脱开。单元划分仍映射到 PADS gates，PCB 封装与器件引脚映射不随栅格改变。

新栅格排版达到有界扩展上限仍存在引脚文字碰撞时，返回错误，不写入该符号的新原理图文件。图形线条和辅助文字使用更细的坐标精度，避免粗栅格抹掉小标记，也避免 25 mil 连接点被再次取整成 10 mil。
