# KiCad 器件库绑定：实现与验证

更新：2026-10-09。已在 0.9.0 实现，沿用器件库的自动同步、设置和同步下拉菜单。

## 文件和使用方式

KiCad 的符号库是一个 `.kicad_sym` 文件；封装库是包含多个 `.kicad_mod` 的 `.pretty` 目录。官方格式见[符号库](https://dev-docs.kicad.org/en/file-formats/sexpr-symbol-lib/)和[封装库](https://dev-docs.kicad.org/en/file-formats/sexpr-footprint/)。

在器件库的 **同步库 → 绑定库文件… → KiCad** 选择 `MyParts.kicad_sym`，对话框显示配套 `MyParts.pretty/` 和 `MyParts.3dshapes/`。每个分类各有一个 AD 绑定和一个 KiCad 绑定，不继承父分类绑定，同一路径不允许绑定多个分类。旧 AD 绑定保持兼容。

首次在 KiCad 的库管理中分别添加符号库与封装库，昵称均用 `MyParts`。之后自动同步更新原路径，按需要刷新或重新打开库。

## 写入行为

- 以 C 编号作为符号、封装、模型的稳定名称；Value 和 MPN 保留真实型号，符号的封装字段写入 `MyParts:C编号`。
- 3D 附带选项沿用设置，封装中的模型变换沿用导出器。模型使用固定绑定位置的绝对路径，不依赖当前工程目录。移动库后应保持配套名称并重新绑定同步，使模型引用更新。
- 使用有字符串、转义、注释和深度限制的 S 表达式解析器。未修改的用户符号、继承定义及未知字段保留原文；同编号更新不会重复追加。
- 生成格式为 **KiCad 9（20241209）**。已有较旧符号库同步后升级格式版本；这是明确的兼容性范围，不承诺继续用 KiCad 6–8 打开升级后的文件。
- `.文件名.jlc-meta.json` 保存本工具管理的内容摘要，请随库保留。同名但非本工具管理的器件，或已被手工改动的管理器件，会报出冲突并保留原件。KiCad 编辑器保存库也可能改变这些内容；这种情况下可先备份，再绑定到新的目标库。
- 一个器件的符号、封装、模型和归属记录共同写入，带文件锁、原件检查、备份和恢复事务。失败后回滚；下次同步会恢复未完成事务。备份在 `.文件名.jlc-backup/`，不删除其他封装、模型和用户文件。
- 移除收藏或解除绑定保留外部库里的器件。导出副本与同步入口分开，普通导出检查绑定路径冲突。

## 已执行验证

核心测试覆盖 Unicode 路径、注释与转义字符串、继承和未知字段、较旧版本升级、同名不同编号、重复同步、无 3D、手工改动冲突、只读文件、并发锁、部分替换失败回滚、恢复记录损坏，以及 AD / KiCad 混合绑定和普通导出路径保护。

Windows 0.9.0 程序实际向含原器件的 AD / KiCad 库追加 C25804、C2040，并重复同步 C25804。KiCad 重复同步后符号文件摘要一致，原有用户封装保持不变。AD 原符号数据和 PCB 原封装、模型等数据流逐字节保留。

使用 **KiCad 9.0.9 官方 kicad-cli** 实际读取同步后的 `.kicad_sym` 和 `.pretty`，成功为新增与原有器件导出 SVG。Windows 界面操作及最终检查详见发布包的验证记录。

## 范围

绑定文件同步与 KiCad 库表注册是两个动作，本版不改写全局或工程库表。已验证 KiCad 官方解析和绘制；尚未在交互式 KiCad 编辑器中验证工程放置和 3D 视觉效果，也未在 Altium GUI 内执行装库与放置。本版不自动向当前工程放置器件。
