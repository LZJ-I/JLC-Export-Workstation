## Agent CLI 与 BOM 自动化

- 新增 `--json`，返回版本化的 JSON 响应、逐项结果和退出码，便于 Agent / Python 脚本调用；`--profile` 可隔离自动化任务的设置与缓存。
- 新增 `bom import / match / show / confirm / export`：导入 CSV / TSV / Excel，保存匹配计划，明确确认候选，再导出 AD / KiCad / PADS。复用 GUI 的 BOM 解析、匹配与导出逻辑。
- 支持按原始 C 编号精确确认、按源表行号选择候选、包含或排除行。确认结果可跨命令保存，重试保留已确认选择，数量和位号保留在计划文件中。
- `batch` / `bom export` 支持 `--merge --name BoardParts`，生成指定名称的 AD / KiCad 合并库；PADS 继续按器件输出。
- 新增 `library inspect`，离线读回 `.SchLib` / `.kicad_sym` 的器件数量、名称、引脚、属性和封装关联。
- Windows 保留子进程与重定向的标准输入输出句柄，便于调用者捕获 JSON。

## 行为调整与修复

- **CLI 选型更明确**：C 编号必须精确匹配；模糊或存在多个匹配的型号不再默认取第一个结果。先搜索并核对，再用明确的 C 编号或 `get --index` 选择。
- 导出前必须确认所有包含的 BOM 行；不完整的计划会在写出文件前停止。下载或格式输出不完整时，通过逐项状态和非零退出码报告。
- 修正合并导出的逐器件路径：KiCad 返回对应器件的实际封装文件，缺失的符号或封装不再被共享库路径掩盖。
- 普通导出会重新生成输出目录中的库文件；`--force` 控制下载资源刷新，并非覆盖保护开关。请使用独立交付目录。
