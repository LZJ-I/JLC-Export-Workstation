## 发布前补充修复

- 修复并发操作中仅靠时钟生成 ID 可能重名的问题；临时资源目录和 AD 元件 ID 使用进程内唯一编号，保持原有八位大写字母格式。
- 修复 Linux 打包环境的 Python 兼容性，增加按已有标签重新构建的发布入口。

## PADS 原理图与封装修复

- 统一调整拥挤器件的外框和引脚间距，保留引脚编号、方向与多单元分组；字号按 7 点输出。
- 修复外框显示为虚线、编辑时找不到管脚封装，以及元件类型名称异常巨大、倾斜的问题。
- 堆叠引脚合并显示重复名称与编号列表，保留全部电气引脚和连接位置，避免外框放大 32 倍后仍然重叠。
- 封装导出保留实心定位标记和长圆焊盘形状。
- 普通 PADS 导出已由用户在 **VX2.7** 验证；**堆叠引脚处理仅通过本地回归与文件预览，尚未经过 PADS 实机验证**。

## 器件库与 BOM

- 支持 BOM 导入、并发匹配和确认具体器件后入库。
- 支持导入现有 AD / KiCad 库，保留源文件、原参数、多单元及继承关系；可独立导出选中器件或当前器件库。
- 可选补充封装和 3D 资源，保留原有绑定。
- 支持 KiCad 绑定同步、进度显示、备份与恢复。

## AD 同步（实验性）

- 提供 AD 编辑器连接、原生插件安装/卸载、等待连接的同步队列及明确选择的离线文件同步。
- 修复中断恢复覆盖用户后来修改的问题：整组文件与备份核验通过后才回滚；发现外部修改、删除或备份损坏时保留现场并停止。
- 旧版事务缺少内容摘要，当前文件与备份不一致时需核对后手动恢复，不自动覆盖。
- **AD 同步仍为实验性功能**。真实 SDK 编译、插件加载和 AD 内编辑需要在目标版本验证，建议先用库副本。

## 下载

解压后运行 Windows 的 `lceda.exe`，或 Linux / macOS 的 `lceda`。发布包含 Windows x64、Linux x64、macOS Apple Silicon / Intel 四个平台包和 SHA-256 校验清单。
